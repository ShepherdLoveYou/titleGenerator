# 中文海报标题生成器

一个用于快速生成头条文章红底白字大标题（1920×1080）的纯前端工具。无需安装、无需服务器，双击 HTML 文件即用。

## 特性

- **多行标题**：支持 2–6 行，自动垂直居中布局
- **背景**：纯色 + 可选图片（cover 铺满），可调高斯模糊（0–300px）和暗化遮罩
- **字体**：黑体 / 宋体 / 微软雅黑 / 楷体 / 仿宋，可调字号、行高、字重
- **颜色**：背景色 / 文字色独立取色器 + Hex 输入
- **导出**：一键下载 SVG 或 PNG（原始 1920×1080），或复制 SVG 代码到剪贴板

## 快速开始

```
git clone https://github.com/ShepherdLoveYou/titleGenerator.git
cd titleGenerator
```

双击 `index.html`，浏览器会直接打开。或在 VS Code 中右键 → Open with Live Server。

不需要 npm、不需要 build、不需要任何依赖。

## 使用提示

- 修改文字 / 颜色 / 模糊 / 字号 → 右侧预览实时更新
- 上传背景图：选本地图片，按 cover 模式自动铺满 1920×1080
- 模糊滑块拉满 150 px 还嫌不够，旁边数字框可以填到 300
- 导出 SVG 文件不嵌入字体，对方机器需有相同字体才能正确显示
- 导出 PNG 总是带正确字体（在浏览器渲染后栅格化）
